# 📊 Sales Performance Analysis

## 🔍 Project Overview
This project analyzes sales data to identify trends, top-performing products, and revenue insights. The goal is to support data-driven decision-making.

## 🛠 Tools Used
- SQL (data analysis)
- Excel (dashboard & visualization)

## 📊 Key Analysis
- Identified top-selling products
- Analyzed monthly sales trends
- Evaluated revenue growth

## 💡 Insights
- Certain products contribute significantly to overall revenue
- Sales show patterns across different time periods
- Data can help improve business decision-making

## 🚀 Outcome
This project demonstrates my ability to clean, analyze, and visualize data using SQL and Excel.
