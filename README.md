Supermarket Sales Performance Analysis
Project Overview

This project presents an interactive Power BI dashboard to analyze supermarket sales performance.
The goal is to identify key business insights related to sales trends, product performance, customer behavior, and regional performance.

This project is part of my Data Analyst Portfolio, demonstrating my skills in data cleaning, analysis, and visualization.

Analyze overall sales performance
