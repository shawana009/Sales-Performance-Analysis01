# Day 7 – Sales Performance Dashboard (Power BI)

## Project Overview
This project is part of my Data Analyst learning journey (Day 7).  
The dashboard provides a detailed analysis of sales performance, helping businesses understand key trends, top-performing products, and regional sales distribution.

The report is designed to support data-driven decision-making through interactive visuals and filters.

## Tools & Technologies
- Power BI
- Excel (Data Source)
- Data Cleaning & Transformation (Power Query)
- Data Modeling
- DAX (Basic Measures)

## Key Features
- Total Sales, Profit, and Quantity KPIs
- Product-wise performance analysis
- Region-wise sales comparison
- Category and Sub-category insights
- Interactive slicers for dynamic filtering
- Clean and professional dashboard layout (recruiter-level design)

## Business Insights
- Identifies top-performing product lines
- Highlights high and low sales regions
- Helps track overall business performance
- Enables quick filtering by category and product
